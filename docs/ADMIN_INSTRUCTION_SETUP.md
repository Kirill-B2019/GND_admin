# Сводная настройка: нода, админка, кошелёк и native_contracts.json

Как связать воедино ноду, админку, кошелёк с Signer Wallet ID и файл `GND_v1/config/native_contracts.json`, чтобы из админки можно было вызывать методы контрактов (запись) без ручной подписи.

---

## 1. Нода (GND_v1)

В каталоге ноды создайте или отредактируйте `.env` (или задайте переменные окружения):

| Переменная | Обязательно | Описание |
|------------|-------------|----------|
| `GND_MASTER_KEY` | Да (для подписи из админки) | 64 hex-символа (32 байта). Без него кошельки не создаются через ноду и не будет автоматической подписи при «Записать контракт». |
| `GND_ADMIN_SECRET` | Да | Любая строка-секрет (например `my-admin-secret-2024`). **Одинаковое** значение задаётся в GND_admin. |
| Подключение к БД | Да | Через `config/db.json` или переменные — хост, порт, имя БД, пользователь, пароль. |

Пример `.env` ноды:

```env
GND_MASTER_KEY=0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef
GND_ADMIN_SECRET=my-admin-secret-2024
```

---

## 2. Админка (GND_admin)

В каталоге GND_admin в `.env` укажите:

| Переменная | Описание |
|------------|----------|
| `GND_NODE_URL` | URL ноды, например `http://127.0.0.1:8182` (без слэша в конце). |
| `GND_ADMIN_SECRET` | **То же значение**, что и `GND_ADMIN_SECRET` на ноде. Иначе админка не сможет вызывать админ-API и подписывать транзакции за кошелёк. |

Пример:

```env
GND_NODE_URL=http://127.0.0.1:8182
GND_ADMIN_SECRET=my-admin-secret-2024
```

(В `config/services.php` используются `GND_NODE_URL` → `services.gnd.node_url` и `GND_ADMIN_SECRET` → `services.gnd.admin_secret`.)

---

## 3. Кошелёк с Signer Wallet ID (from для «Записать контракт»)

Чтобы при вызове «Записать контракт» нода сама подписывала транзакцию, кошелёк **from** должен быть создан **через ноду** (тогда у него появляется Signer Wallet ID).

1. Запустите ноду с заданным `GND_MASTER_KEY` и `GND_ADMIN_SECRET`.
2. В админке: **Кошельки** → **Создать кошелёк** → нажмите **Создать**.
3. Откройте созданный кошелёк: на странице кошелька должно быть поле **Signer Wallet ID** (не пустое). Этот кошелёк и используйте как **from** во вкладке «Записать контракт».

Если кошелёк создан не через ноду (например вручную в БД), у него не будет Signer Wallet ID — нода не сможет подписать за него запрос из админки.

---

## 4. Файл native_contracts.json на ноде

Файл лежит в **GND_v1/config/native_contracts.json**. В нём задаются:

| Поле | Назначение |
|------|------------|
| `gnd_contract_address` | Адрес задеплоенного контракта GND (после деплоя по разделу «Деплой GND и GANI через админку»). |
| `gani_contract_address` | Адрес задеплоенного контракта GANI. |
| `fee_collector_address` | Адрес кошелька, куда собираются комиссии (по желанию). |
| `gndself_address` | Адрес «системного» кошелька: контракты с таким владельцем освобождаются от комиссии за газ. Удобно указать адрес кошелька, созданного через ноду (п. 3), чтобы при вызовах от его имени комиссия не списывалась. |

Порядок действий:

1. Сначала можно оставить `gnd_contract_address` и `gani_contract_address` пустыми.
2. После деплоя Controller, GND и GANI через админку скопируйте адреса контрактов из карточек контрактов и впишите в `gnd_contract_address` и `gani_contract_address`.
3. В `gndself_address` впишите адрес кошелька из п. 3 (с Signer Wallet ID), если хотите использовать его как системный (например для вызова `setGaniToken` без комиссии). Сохраните файл и при необходимости перезапустите ноду (если конфиг читается при старте).

Пример заполненного фрагмента (адреса — примеры):

```json
{
  "gnd_contract_address": "GNDct...",
  "gani_contract_address": "GNDct...",
  "fee_collector_address": "GNDKmzR2WCWrAzX4jQGMKaFEiNJDbowbVzaU",
  "gndself_address": "GN_FRTb5xeLYuFsb5qCYsKaqQu6FJzE8GftW"
}
```

---

## Краткий чеклист

- [ ] На ноде заданы `GND_MASTER_KEY` (64 hex) и `GND_ADMIN_SECRET`.
- [ ] В GND_admin в `.env` заданы `GND_NODE_URL` и тот же `GND_ADMIN_SECRET`.
- [ ] В админке создан хотя бы один кошелёк (у него есть Signer Wallet ID).
- [ ] В «Записать контракт» выбран этот кошелёк как **from** — подпись выполнит нода.
- [ ] После деплоя GND/GANI адреса контрактов прописаны в `GND_v1/config/native_contracts.json`.
- [ ] При необходимости в `gndself_address` указан адрес системного кошелька (тот же, что используется как from).
